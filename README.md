# Synapse Care

Synapse Care is an AI-powered holistic health assistant built to unify mental and physical well-being in one interactive platform. The system screens emotional distress from chat interactions and simplifies complex medical lab reports into clear, human-readable insights for preventive awareness.

The project is built to educate, assist, and detect early risk signals, helping users stay informed and proactive with their health data without replacing medical professionals.

## 🚀 Overview

Synapse Care is a unified wellness system featuring:
- AI chat companion for emotional and general health interaction
- Keyword-based mental health risk screening
- Lab report simplification into easy explanations
- Interpretation of test values with timestamps
- Centralized wellness responses from uploaded reports
- No external hardware needed
- Focus on prevention and clarity

This project demonstrates how AI can be used for early emotional risk awareness and medical data education in one cohesive platform.

## ✨ Features

1. **AI Companion Chat**
- Generates conversational health-aligned support.
- Screens interaction keywords for stress, panic, or crisis signals.

2. **Lab Report Processor**
- Converts complex medical terminology into easier insights.
- Explains abnormal ranges without diagnostic claims.

3. **Awareness Layer**
- Helps users understand emotional state and health data holistically.
- Provides preventive suggestions, not clinical decisions.

4. **Health Interpretation**
- Human-readable, session-based responses.
- Processes lab values in simplified structured feedback.

## 📁 Project Structure

## 🛠 Installation & Setup

1. **Install Dependencies**
- Use Python and any web-friendly AI UI framework.
- Load API keys securely using environment variables (`.env`).

2. **Generate API Keys**
- Requires any LLM API key (Gemini or similar) to power chat and report simplification.

3. **Run the Application**
- Start the chat interface or upload lab reports to receive unified wellness feedback.
